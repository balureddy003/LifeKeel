# @lifekeel/runtime

Replaceable runtime ports and reference in-memory adapters for the
outcome-lifecycle model defined in `@lifekeel/specifications`. Depended on
by `@lifekeel/platform`, `@lifekeel/mongodb-adapter`, `@lifekeel/conformance`,
and `@lifekeel/workflows` — a swap-in point if the outcome storage ever
needs a non-Mongo backend.
