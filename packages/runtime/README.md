# @agentoak/runtime

Replaceable runtime ports and reference in-memory adapters for the
outcome-lifecycle model defined in `@agentoak/specifications`. Depended on
by `@agentoak/platform`, `@agentoak/mongodb-adapter`, `@agentoak/conformance`,
and `@agentoak/workflows` — a swap-in point if the outcome storage ever
needs a non-Mongo backend.
