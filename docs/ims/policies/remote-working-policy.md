ISO/IEC 27001 A.6.7, A.7.3, A.7.7–A.7.10, A.7.13, A.7.14, A.8.1. Data-centre physical controls
are inherited from cloud suppliers (`docs/ims/scope.md` §5); this policy covers staff devices
and home offices.

## Statements

1. Any device used for LifeKeel work has full-disk encryption, automatic OS updates, a screen
   lock of 5 minutes or less, endpoint protection, and is enrolled in device management that
   can wipe it remotely.
2. Lock the screen when away; work so that household data on screen is not visible to others.
3. No removable media for C3/C4 information (classification policy).
4. Use a trusted network; no shared or public computers for LifeKeel access.
5. Report a lost or stolen device immediately as a security incident.
6. Devices are wiped (with a record) before disposal or reassignment.

## Status

None of these controls is evidenced in the repository today. Device controls are G-PEO-02
(MDM, FDE, EDR evidence); records are kept outside the repository.
